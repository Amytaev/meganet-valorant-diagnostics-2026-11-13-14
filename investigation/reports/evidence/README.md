# Происхождение отобранных данных

**Публичная обезличенная копия.** Числовые измерения, времена и целевые/транзитные IP сохранены. Личные сетевые идентификаторы и локальные пользовательские пути заменены стабильными обозначениями. Упоминаемые исходные размеры и хеши относятся к приватному источнику; актуальные публичные хеши — в SHA256SUMS.txt. Полные native ping/tracert сохранены побайтно. Подробнее — корневой PUBLICATION-NOTES.md.

Каталоги с именами сессий содержат выбранные CSV/JSONL и начальные технические снимки непосредственно с игрового ПК. Raw остаётся локально/игнорируется. `DONE` позволяет воспроизвести состояние завершения при повторном анализе; `metadata.json` содержит фактический конец и причину остановки.

* `20261113-234606-Range-721321`: квалифицированный Range, завершён вручную STOP при переходе игрока в матч, 140 проб на цель. Показания игрока сохранены отдельно от ICMP.
* Каталог `Stockholm-unrated`: отдельный 10-минутный сбор после подтверждения игроком входа в обычный матч с выбранным Stockholm. Название региона — сообщение игрока; независимой геолокации игрового UDP нет.
* `20261114-000610-Stockholm-unrated-ee0d94`: возобновлённый после скриншота сбор, 123 пробы на цель, сообщение игрока о продолжающемся эпизоде и TTL-проход. Первый скриншотный пик находится в пробеле, а не в этом окне.
* `20261114-001022-Stockholm-unrated-c5ba53`: 149 проб на цель, замена одного контрольного узла на свежий отвечающий hop 87.245.233.166; игрок сообщил восстановление. Не объединять этот узел с 87.245.234.191 как одну цель.
* `probe-quality-control`: 25 строк первой неоднозначной серии (5 циклов) плюс её исходные metadata; полный 30-пробный последовательный контроль и 10-пробный native ping. Число циклов в metadata относится ко всей исходной первой сессии, а не к экспортированному примеру. Проценты её тайм-аутов не выдавать за сетевые потери. Начальные кандидаты игрового журнала — исторические, не доказанные активные peers.

Экспортированы только заданные схемой поля счётчиков/сокетов, технические данные интерфейсов, исходные ICMP-статусы и разрешённые поля журнала. Полные игровые строки и файлы авторизации исключены. SSID/BSSID, IP-адреса и относящиеся к задаче данные разрешены владельцем для этой приватной ветки.

В `wlan.jsonl` сохраняется исходная декодировка; `wlan-readable.jsonl` — отдельное обратимое восстановление меток UTF-8/CP866 с описанием преобразования. `analysis.json` пересчитывается офлайн; результаты игр не выводятся из TCP или ICMP. Нули драйверных PHY-счётчиков при активном трафике нельзя трактовать как отсутствие retries.

В первой TTL-выгрузке API вернул целевой IP в `reply_address` при статусе TimedOut. Такая строка не содержит ответившего hop; для списка узлов используются только TtlExpired/Success. `response_wait_ms` — ожидание процесса, не сертифицированный RTT маршрутизатора. Конечный адрес не ответил в пределах 16 TTL; не трактовать это как 100% потерь UDP. Новая версия скрипта очищает reply_address при timeout.

`SHA256SUMS.txt` проверяет целостность выбранных файлов, но сам по себе не удостоверяет точность часов, отсутствие sampling bias или происхождение на аппаратном уровне. После изменения analysis/таблиц обновлять manifest, не изменяя исходные числовые пробы.

Воспроизведение из корня репозитория (подставить имена существующих каталогов):

Локальный `.gitattributes` запрещает преобразование окончаний строк внутри evidence: хеши относятся к сохранённым байтам и должны совпадать после клонирования, включая исходный BOM/CRLF. Это не отключает проверку содержимого на секреты.

```powershell
python valorant-network-investigation/scripts/analyze_session.py valorant-network-investigation/reports/evidence/ИМЯ-СЕССИИ
python valorant-network-investigation/scripts/write_metrics.py КАТАЛОГ-RANGE КАТАЛОГ-МАТЧА --output valorant-network-investigation/reports/SESSION-METRICS.md
```
