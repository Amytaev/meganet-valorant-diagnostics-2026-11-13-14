# Финальный неизменённый журнал

**Публичная обезличенная копия.** Числовые измерения, времена и целевые/транзитные IP сохранены. Личные сетевые идентификаторы и локальные пользовательские пути заменены стабильными обозначениями. Упоминаемые исходные размеры и хеши относятся к приватному источнику; актуальные публичные хеши — в SHA256SUMS.txt. Полные native ping/tracert сохранены побайтно. Подробнее — корневой PUBLICATION-NOTES.md.

Источник: local Windows run 625146fb9ba34394affe537101b3db0b, PID 9936. Стандартный STOP по явной команде пользователя, 14 ноября 2026 01:08:36 (+05:00).

Два telemetry JSONL, metadata/status/DONE и segments скопированы побайтно после закрытия писателя. SHA-256 находятся в ../SHA256SUMS.txt. Никакие строки и временные метки не исправлялись. analysis.latest.json и FINAL-RESULTS.md — автоматический итог базового анализатора; подробный аудит и причинные ограничения находятся в ../../INVESTIGATION-RESULTS.md и ../../final-data/final-analysis.json.

Важно: original segments.json имеет first_seq=2313 для второго файла, хотя его первая фактическая строка — 2312. Все sequence 1–3299 непрерывны; это ошибка границы метаданных без потери данных. Для аудита используются физические строки. Исправление кода относится только к будущим запускам.

marker-clarification.json сохраняет последующее уточнение пользователя: единственный F10 note — проверка кнопки/другое событие, не подтверждённый скачок или восстановление. Не подставлять к нему вымышленные игровые RTT/loss.

Журнал содержит только заданные схемой ICMP/системные поля. Это не pcap, не дамп игрового UDP, не полный игровой лог и не дамп памяти. Наличие процесса игры не доказывает режим/регион. Начальные исполняемые исходники с совпадающими SHA сохранены в ../continuous-v3-validation/started-source/.
